## Project Overview

BankApp demonstrates a banking-focused frontend that starts with an introductory landing screen before opening the central application view. The project concentrates on organizing and presenting a banking interface in the browser without depending on a large frontend framework.

Every part of the implementation uses standard HTML, CSS, and JavaScript. Because the code remains framework-free, it can serve as a practical example for exploring layouts, navigation between views, and basic browser-side behavior.
